# GreenSpace

  GreenSpace — это личный некоммерческий проект, разработанный под лицензией Apache License 2.0.
Созданный с использованием NextJS, React и TypeScript.
Соддержит кастомные компоненты вдохновлённые быстро-развивающимися возможностями CSS. 
А при стилизации сайта искался баланс между скоростью и эстетичным видом.
Кодовая база спроектирована по принципу слоёв, где каждый компонент организован в стиле модулей.

## Предпросмотр через static export от NextJS:
- По ссылке: [https://web-sender.github.io/green-space/](https://web-sender.github.io/green-space/)

## Ключевые особенности
- **Next.js**: Использует серверный рендеринг и статическую генерацию страниц для высокой производительности и оптимизации SEO.
- **TypeScript**: Повышает надежность и удобство поддержки кода за счет строгой типизации.
- **Собственная реализация**: Содержит компоненты и стили, написанные с нуля, что обеспечивает гибкость и контроль над кодом.
- **Слоевая архитектура**: Структурирована для удобного обслуживания и будущего расширения с разделением компонентов на слои абстракций.

## Требования
- Node.js >= 18.x
- npm >= 9.x

## Начало работы

1. Клонируйте репозиторий:
  ```bash
    git clone https://github.com/web-sender/green-space.git
    cd myapp-client
  ```

2. Установите зависимости:
  ```bash
    npm install
  ```

3. Запустите сервер разработки:
  ```bash
    npm run dev
  ```

4. Откройте [http://localhost:3000](http://localhost:3000) в вашем браузере.

5. Для продакшен-сборки:
  ```bash
    npm run build
    npm run start
  ```

## Структура проекта
Проект организован на базовой основе слоевой архитектуры "Feature-Sliced Design":
```
├── data/                      # Используется для хранения текстового контента и url адресов на статические ресурсы
├── lib/                       # Используется для хранения общих микропрограмм и утилит
│   ├── form/                  # Функции для обработки формы
│   └── hooks/                 # Кастомные хуки
├── public/                    # Статические ресурсы (изображения)
│   ├── icon/                  # Иконки, включая активы для социальных сетей
│   │   └── social/
│   ├── main/                  # Общие изображения для страниц и секций
│   └── media/                 # Видео файлы
├── src/
│   ├── app/                   # Роутер Next.js
│   ├── fonts/                 # Локальные шрифты
│   └── styles/                # Глобальные стили
├── widgets/                   # Высокоуровневые компоненты используемые как блоки секций или полноценные интерфейсы
│   ├── SelfWidgets/           # Самостоятельные высокоуровневые компоненты для страниц
│   ├── LayoutWidgets/         # Готовые к использованию Layout интерфейсы для страниц
│   └── SectionWidgets/        # Блоки секций используемые напрямую в страницах
├── features/                  # Полнофункциональные интерфейсы предназначенные для секций или высокоуровневых компонентов
├── entities/                  # Небольшые компоненты для features интерфейсов
└── shared/                    # Малые компоненты вынесенные для удобства и избежания нагромождения в других компонентах/интерфейсах
```
Текстовый контент и ссылки на media управляются через JSON-файлы в src/data/, и импортируются в секционные и layout компоненты, 
 а изображения организованы в public/ по группам - разделяя основные изображения, лого и видео файлы. 
Компоненты разделены по слоям, для общего доступа через alias в tsconfig, 
 а также используют модификаторы типа "widgets--section" для гибкого объединения по смысловым группам.
Папка lib/ содержит глобальные вспомагательны микропрограммы, такие как хуки и функции обработки формы.

## Детали реализации
Отдельно про компонент VideoCube:
Был разработан при помощи свойств css для 3D трансформаций;
В ходе разработки были реализованы модульные функции,
  для безшовного позиционирования и управление тенями,
  а также жесты для управления вращением куба по X (rotateX) и Y (rotateY).

## Доступные скрипты
- `npm run dev` — Запускает сервер разработки.
- `npm run build` — Собирает приложение для продакшена.
- `npm run export` — Собирает приложение для статического экспорта.
- `npm run start` — Запускает собранное приложение в продакшен-режиме.
- `npm run lint` — Запускает встроенную конфигурацию ESLint от Next.js для проверки качества кода.
